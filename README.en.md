# KixDNS

[简体中文](./README.md) | **English**

KixDNS is an asynchronous, non-recursive DNS forwarding server written in Rust. It accepts queries over UDP and TCP (optionally DoH), then follows ordered pipeline rules to forward them upstream or to build the response itself.

This repository is a fork of [olicesx/kixdns](https://github.com/olicesx/kixdns): upstream code plus our fixes and the panel interface, released under date versions (see [Releases](https://github.com/tuoro/kixdns/releases)) and installed and updated by [KixDNS Panel](https://github.com/tuoro/kixdns-panel).

> Notice: this project is entirely built by AI (content, documentation, and the initial implementation were generated by AI).

## Managing it with the panel

Use it with [KixDNS Panel](https://github.com/tuoro/kixdns-panel): one command installs the panel and this kernel; then, in the browser, you edit the configuration (checked before saving, rolled back when a hot reload fails), watch traffic, run DNS diagnostics and update the kernel. See the panel's [installation notes](https://github.com/tuoro/kixdns-panel#安装).

## Features

- **Inbound**: DNS over UDP and TCP, optional DoH (RFC 8484).
- **Upstreams**: UDP, TCP, TCP and UDP at once, DoH, DoT, DoQ (RFC 9250); several upstreams are queried at once and the first usable answer wins.
- **Routing**: pick pipelines and rules by listener label, client address, domain, query type and class, EDNS, GeoIP and GeoSite; combine matchers with and, or, and_not and or_not.
- **Answer-based handling**: judge the answer IP, RCODE, record type, TXT content and more, then fall back to another upstream, filter or replace the answer, or jump to another pipeline.
- **Static answers**: RCODE, A/AAAA, CNAME, TXT.
- **Cache**: capacity, TTL floor and cap, merged concurrent misses, background refresh, serve-stale (RFC 8767); answers kept per ECS scope (RFC 7871).
- **GeoIP and GeoSite**: MaxMind MMDB, V2Ray GeoIP and GeoSite data; a built-in command converts GeoIP `.dat` to MMDB.
- **Hot reload**: the configuration, GeoSite and GeoIP `.dat` data and the DoH certificate files take effect when they change; an invalid new configuration or certificate keeps the previous one.
- **Performance**: tokio async I/O, a UDP socket per worker, forwarding without full packet parsing when no rule needs it, optional adaptive flow control.

## Running on its own

Without the panel:

~~~bash
cargo build --release
./target/release/kixdns run -c config/pipeline.json
~~~

It listens on UDP and TCP `0.0.0.0:5353` and forwards to `1.1.1.1:53` by default. It needs a toolchain that supports Rust edition 2024.
